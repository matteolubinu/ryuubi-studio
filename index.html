Questions

Before you buy

What exactly do I download?

A zip with a folder in the open Agent Skills format: SKILL.md, a worked example and templates in references/, a README with step-by-step installation and a license file. All in English, plain Markdown, yours to keep.

Which AI do I need?

Any assistant that handles long instructions. Tools that support the open SKILL.md format (Claude, OpenAI Codex, Cursor, GitHub Copilot, Gemini CLI and others) load it as a real skill. In ChatGPT or Gemini you paste it into a custom GPT, a Project or a Gem. Without any AI, the files still work as step-by-step guides.

Can I use them for commercial projects?

Yes, for your own projects, commercial ones included. You can't resell or redistribute the files. Read the license.
